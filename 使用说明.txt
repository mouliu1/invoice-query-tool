数金数据查询工具 - 使用说明
============================================

本工具整合了多类接口，全部在同一个程序里：
  一、发票查询（按纳税人识别号）
  二、不动产查询（申请人直接写库链路：申请提交 / 查询申请记录 / Excel补录 /
                 编辑资产结果 / 处理回调）
  三、公积金收入评分（单个 / 批量 / 历史记录）
  四、探知风控数据（名下车辆状况分析(ETC开户人/车辆所有人) / 名下车辆总价值 /
                 车五项信息查询 / 车辆价值查询 / 商业保险有效性判定 /
                 名下车辆估值+商业险 / 多头借贷指数 / 支付行为指数 / 全景指数 /
                 消费交易特征 / 特定风险名单 / 信用指数；
                 单个 / 批量 / 导出，返回结果自动附带中文字段注释）

------------------------------------------------
一、文件
  - 数金数据查询工具.exe        主程序，双击运行即可，无需安装Python
  - 使用说明.txt                本说明

二、首次使用（重要）
  1. 双击 “数金数据查询工具.exe” 打开程序
  2. 在顶部 Authorization 输入框中填入接口授权令牌（所有接口共用）
     - 只需填 Token 本体即可，程序会自动补上 “Bearer ” 前缀
     - 如果你粘贴的内容已带 Bearer/Basic 等前缀，则原样使用
  3. 点击右侧 “保存”，下次打开会自动带回
     （保存在用户目录的 .invoice_query_tool_config.json 中）
  4. 输入框默认隐藏，勾选 “显示” 可明文查看

  接口地址需访问 https://api.dlszjr.com ，请确保网络可达。
  另：“四、探知风控数据”是另一套服务，需访问 https://api.tanzhishuju.com ，
      且使用单独的 apiKey / apiSecret 凭证（在该模块内单独填写并保存），与上方
      Authorization 不通用。

------------------------------------------------
三、发票查询
  【单个查询】
    1. 输入纳税人识别号，点击 “查询”
    2. 程序先提交再轮询，直到 成功/失败/无数据/超时
    3. 文本框显示完整原始 JSON
    4. 可 “导出本次结果到Excel”
  【批量查询（Excel导入）】
    1. 点击 “生成导入模板” 生成空白模板（第一列：纳税人识别号）
    2. “选择...” 选择Excel → “开始批量查询”
    3. 过程中可 “取消”，完成后 “导出全部结果到Excel”

  导出Excel结构：查询汇总 + 企业信息 + 开票汇总 + 上游/下游开票分类
                + 客户销售地区 + 商品销售（每张明细表首列带纳税人识别号）

------------------------------------------------
四、公积金收入评分
  【单个查询】
    1. 输入 姓名、身份证号（必填）、手机号（可选）
    2. 点击 “查询”，程序提交后自动轮询评分结果
    3. 状态：成功(Succeeded)/无数据(NoData)/失败(Failed)/超时
    4. 可 “导出本次结果到Excel”
  【批量查询（Excel导入）】
    1. 点击 “生成导入模板”（三列：姓名、身份证号、手机号）
    2. 选择Excel → “开始批量查询” → 完成后导出
  【历史记录】
    输入页码/每页条数，点击 “查询历史”，列出当前账号已提交的评分记录

  导出Excel：单表“公积金评分结果”，含 评分、评分区间、缴存状态、
            第三方返回码/说明、流水号、计费标识、受理ID、时间等

------------------------------------------------
五、不动产查询（申请人直接写库链路，重要）
  本接口为“申请人直接写库”链路（/search/assets/application）：先把申请人直接写入
  申请记录表，资产结果靠人工/Excel 补录，最后触发回调。鉴权与发票/公积金一致，使用
  同一个 Authorization（自动补 Bearer 前缀），无需公网回调服务器，所有操作都在本
  工具内通过调用数金接口完成。

  重要说明（读 vs 写）：
    - 不动产资产数据在本链路里不是系统自动查出来的，而是靠“③ Excel补录”手工填进去。
    - 若数据已由别人/别的流程录好，你只用“② 查询申请记录”就能看到结果，用不到 ③④。
    - 若没人补录，② 查到的记录会一直是“进行中”、没有资产明细。
    因此“③ Excel补录 / ④ 编辑资产 / ⑤ 处理回调”都属于“管理端写入/触发”功能，
    程序里默认隐藏；纯查询无需关心。需要录入/修改/回调时，勾选不动产页顶部的
    “显示‘③ Excel补录 / ④ 编辑资产 / ⑤ 处理回调’” 即可显示这三页。

  =========================================================
  ★ 我只想“查询不动产”，具体每一步怎么操作？
  =========================================================
    前提：要查的申请人已经登记过（① 提交过），且资产结果已被补录。

    第1步：打开程序，在顶部 Authorization 填入令牌并“保存”（仅首次）。
    第2步：点上方“不动产查询”大标签，进入后默认只看到 ①② 两个子页
           （③④⑤ 已隐藏，不用管）。
    第3步：点“② 查询申请记录”子页。
    第4步：在“关键词”里输入 姓名 或 身份证号 或 请求单号（也可留空查全部），
           可设页码/每页条数，点“查询”。
    第5步：列表里看到对应记录：请求单号、姓名、身份证、申请状态、是否已回调、
           回调配置ID、申请记录ID、资产条数。
           - “申请状态=成功”且“资产条数>0” 表示已有不动产结果。
           - 若状态还是“进行中”、资产条数为 0，说明尚未补录，暂时查不到资产明细。
    第6步：点“导出Excel”，得到两张表——“申请记录”和“资产明细”
           （资产明细含 房产证号/单元号/权利人/权利类型/用途/面积/坐落/
           是否查封/是否抵押 等）。
    完成。整个查询过程只用到“② 查询申请记录”这一个子页。

    （如果你要查的人还没登记过，先到“① 申请提交”填姓名+身份证提交，再让相关人员
     做补录，之后回到“②”查询即可。）

  -------------------- 各子页功能明细 --------------------
  【① 申请提交】（登记申请人，纯查询时一般不需要）
    页面分三块：方式一 手动添加、方式二 Excel批量导入、下方“待提交列表”。
    两种方式录入的人都会进入“待提交列表”，核对无误后统一点“提交申请”。
    方式一·手动添加：
      1. 填 姓名 + 身份证号，点 “添加到列表”（可重复加多个）
      2. 选中某行可点 “移除选中” 删除
    方式二·Excel批量导入：
      1. 点 “生成导入模板”，得到两列模板：姓名、身份证号
      2. 填好后点 “选择...” 选择该 Excel
      3. 点 “导入到列表”，名单读入“待提交列表”（仅导入、不提交；自动与已有项去重，
         姓名或身份证为空的行会跳过）
    最后：在“待提交列表”里核对（底部显示“待提交：N 人”），确认无误后点 “提交申请”，
         一次性提交全部；“清空列表” 可清空重来。
    注意：本接口不接收企业名称/信用代码/文件，也不返回 reqOrderNo；
         请求单号请到“② 查询申请记录”取回。

  【② 查询申请记录】（查询不动产就用这一页）
    1. 可填关键词（匹配请求单号/姓名/身份证）、每页条数，点 “查询”
       （关键词框按回车也会从第1页查起）
    2. 列表展示：请求单号、姓名、身份证、申请状态、是否已回调、回调配置ID、
       申请记录ID、资产条数；列表带上下/左右滚动条，数据多也能浏览
    3. 分页导航（列表下方）：首页 / 上一页 / 第[页码]/共N页 / 跳转 / 下一页 / 末页；
       直接在页码框输入数字回车即可跳转（超出范围会自动取最近的有效页）
    4. 结果管理：选中一行（可按 Ctrl/Shift 多选）点 “删除选中行”；或 “清空结果”
       清掉整页显示。注意：删除/清空只清理本地显示，不影响服务器上的记录
    5. 选中一行可：复制单号 / 填入“③ 补录页” / 加入“⑤ 回调页”
       （点后两个按钮会自动显示并跳到对应的 ③ 或 ⑤ 页）
    6. “导出Excel”：申请记录 + 资产明细 两张表

  【③ Excel补录】（默认隐藏，管理端写入用）
    1. “生成补录模板” 生成模板。必填列：Name、CardNum、ReqOrderNo
       （须与申请记录一致）；其余为资产结果列（best-effort，具体补录列以数金
       实际校验为准）
    2. “选择...” 选 Excel，填 reqOrderNo（建议带上，服务端会校验一致），
       点 “开始补录”
    3. 补录成功后该申请记录状态更新为“成功”，并写入资产结果表

  【④ 编辑资产结果】（默认隐藏，管理端写入用）
    1. 填 资产ID assetId（必填）；reqOrderNo 选填（二次保护）
    2. 其余字段（房产证号/单元号/权利人/权利类型/用途/面积/坐落/是否抵押/
       是否查封）留空则不修改
    3. 点 “提交修改”

  【⑤ 处理回调】（默认隐藏，管理端触发用）
    1. 在文本框每行填一个 reqOrderNo（可多个），或从“②”用“选中单号→回调页”加入
    2. 点 “执行回调”，对请求单号数组调用 /callback/handle
       （至少一条成功即整体返回成功；每条返回是否成功/失败原因/处理时间）

------------------------------------------------
七、探知风控数据
  本模块为另一套服务（上海勃池/探知数据），认证方式与前面不同：使用 apiKey + apiSecret
  做 SHA-1 签名，程序内部自动完成签名与提交，你只需填好凭证即可。

  【准备】
    1. 进入“探知风控数据”大标签，在顶部“探知数据 API 凭证”里填入 apiKey 与 apiSecret，
       点“保存”（下次自动带回；apiSecret 默认隐藏，勾“显示”可查看）。
    2. 在“查询产品”下拉框选择要查的接口，右侧会提示该产品的必填项。

  【查询产品与必填项】
    - 名下车辆状况分析(ETC开户人) / 名下车辆状况分析(车辆所有人)：身份证号必填（姓名选填）
      两者区别是关系类型 usertype：ETC开户人=1、车辆所有人=2，分别查不同口径的名下车辆
    - 名下车辆总价值：身份证号/企业代码必填（均18位）
    - 车五项信息查询：车牌号必填（按车牌反查品牌/型号/发动机号/VIN等）
    - 车辆价值查询：车牌号 + VIN(车架号) 均必填（缺一不可，与文档要求一致）
    - 商业保险有效性判定：车牌号 + VIN(车架号) 均必填（缺一不可）
    - 多头借贷指数 / 支付行为指数 / 全景指数 / 消费交易特征 / 特定风险名单 / 信用指数：
      姓名、身份证号、手机号 均必填
    - 名下车辆估值+商业险：身份证号必填（姓名选填），详见本节末“特别产品”

    说明：选中车牌类产品（车五项信息查询/车辆价值查询/商业保险有效性判定）时，
    单个查询页的输入框会自动切换——“身份证号”变为“车牌号”，“姓名”变为“VIN(车架号)”
    （车五项信息查询不需要 VIN，该框会自动禁用），“手机号”框对这三个产品不适用、自动禁用。
    批量导入模板也会相应变为“车牌号[/VIN]”两列（不再是姓名/身份证号/手机号）。

  【单个查询】
    1. 选好产品，填姓名/身份证号/手机号（按提示），点“查询”
    2. 上方表格按“字段 / 中文名 / 值 / 说明”展示解析后的结果，中文注释来自数据字典；
       下方文本框展示原始返回 JSON
    3. 可“导出本次结果到Excel”（纵向：字段|中文名|值|说明）

  【批量查询（Excel导入）】
    1. 点“生成导入模板”得到三列模板：姓名、身份证号、手机号
    2. “选择...”选好 Excel，确认上方“查询产品”后点“开始批量查询”（可“取消”）
    3. 完成后“导出全部结果到Excel”：按产品分Sheet，前两行为
       “字段码 / 中文名注释”双表头，每人一行，便于核对每个返回参数的含义
    4. “清空结果”可清空当前批量列表

  说明：状态码 0000=查得(计费)；8002=查询成功无数据(不计费)；1013=参数格式错误；
       1015=余额不足；8000/8001/8003=通道或内部异常。注释覆盖度依据所提供的
       “风控产品数据字典标注”，个别字段如未收录则中文名留空、值照常显示。

  ★ 特别产品：“名下车辆估值+商业险”（身份证自动串联四个接口）
    这是把四个接口串起来的合并产品，只需输入身份证号（姓名选填），程序自动：
      ① 名下车辆状况分析：同时查 ETC开户人(usertype=1) 与 车辆所有人(usertype=2)
         两种关系类型，按车牌合并去重，拿到车牌列表（同车牌只查一次后续接口）；
      ② 对每一辆车，用车牌查“车五项信息查询”，反查出该车的 VIN(车架号)，
         顺带拿到车辆品牌、型号、发动机号、车辆类别、使用性质、首次上牌日期；
      ③ 拿到 VIN 后，用 VIN+车牌 一起查“车辆价值查询”得到车估值；
      ④ 用 VIN+车牌 一起查“商业保险有效性判定”得到 1=有效 / 0=无效。
    注意：③④两个接口都要求 VIN 和车牌同时提供（文档写的是均必填，且请求样例也是
    两个一起传），并非二选一；此前版本只传了车牌导致必然返回 1013(参数格式错误)，
    现已修正为先查 VIN 再一起传。另外商业险接口的文档表格把参数名写成大写“VIN”，
    但实测传大写会返回“vin不能为空”，服务端实际按小写“vin”校验（与车估值一致）；
    本工具已按实测结果统一传小写 vin，无需你操心。
    若某车牌查不到 VIN，会跳过③④两步，对应状态码标为 SKIP 并说明原因，不做无意义调用。
    结果按“每辆车”展开：数据来源、车牌号、车型、车牌颜色、VIN、品牌、型号、发动机号、
    车辆类别、使用性质、首次上牌日期、车辆估值(元)、商业保险有效性 等；
    其中“数据来源”标注该车牌来自 ETC开户人 / 车辆所有人（两者都有则都列出）。
    单查在表格里逐辆显示，批量导出每人一行、同一字段多辆车用“；”合并。
    批量模板只需两列：姓名、身份证号（车牌和VIN都由程序自动串联获取，无需手填）。

  ★ 状态码说明会自动翻译
    结果表格/单查导出的“说明”列，只要字段是 code 或 xxx_code，都会自动把状态码数字
    翻成中文含义（如 1013→参数格式错误、8002→查询成功未查得等），不用再去翻接口文档；
    批量导出因为没有逐格“说明”列，改为在每个产品 Sheet 数据下方附一段状态码对照表。

------------------------------------------------
六、注意事项
  - 发票/公积金为“提交+轮询”，单条可能需几秒到一两分钟，请耐心等待
  - 不动产“申请提交”不返回 reqOrderNo，请到“查询申请记录”按姓名/身份证取回
  - Excel补录上传须与申请记录一致（Name/CardNum/ReqOrderNo 三列必填）
  - Authorization 为前三类接口共用，程序会自动补 “Bearer ” 前缀
  - “探知风控数据”使用单独的 apiKey/apiSecret，访问 https://api.tanzhishuju.com
  - 各接口的数据可见范围取决于该 Token / 凭证对应账号的权限
  - 程序首次启动较慢（onefile模式需解压），后续会更快
  - 若 Windows Defender 提示，因为是PyInstaller打包的未签名程序，
    可点击 “更多信息 -> 仍要运行” 放行
